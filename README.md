**天赋技能点**：

## 我信的三件事

1. **想法不值钱，做出来才值钱。** 把 idea 变成 demo，把 demo 变成开源项目，把开源项目变成有人真的在用；
2. **不拿别人的地图丈量自己的路。** 有人开局是参天大树，有人开局是花草藤蔓——没有谁的地图更高，只有适配与否；
3. **低谷是用来渡过的，不是用来熬垮的。** 风不顺的时候慢一点、养一养，多借借贵人的力。
